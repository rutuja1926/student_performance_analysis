## Project Overview

Student Performance Analysis is a data analytics project that explores factors affecting students' academic performance. The project includes data cleaning, visualization, exploratory data analysis (EDA), and predictive modeling to gain meaningful insights.

## Key Features

1) Data Cleaning & Preprocessing

2) Exploratory Data Analysis (EDA)

3) Data Visualization

4) Feature Engineering

5) Student Performance Prediction

6) Business Insights & Recommendations

## Tech Stack

Student Performance Dataset
